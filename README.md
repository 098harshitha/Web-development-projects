# Web-development-projects
My hands-on Web Development learning journey.

PROJECT-1 = Event registration webpage(HTML)

1. Start by creating an HTML document .
2. Add the webpage title using the `<title>` tag and create the event heading using `<header>`.
3. Create an event details section using `<section>`, headings, and `<p>` tags.
4. Insert an event image.
5. Create the event schedule using table tags.
6. Create a registration form using `<form>`, `<label>`, `<input>`, `<select>`, `<textarea>`, and `<button>` tags.
7. Add radio buttons and checkboxes.
8.Embed the event location using the `<iframe>` tag.
9. Add contact details and the  using `<footer>`, `<p>` tags.
10. End the document by closing all HTML tags and save it as `index.html`.

PROJECT-2 = Restaurant Menu Card (HTML & CSS)

1.Start by creating an HTML document.
2.Add the webpage title using the <title> tag.
3.Create the food items using <div>, <strong>, and <p> tags.
4.Add a short description for each food item.
5.Add the price of each food item using <span> tags.
6.Add an offer using the <strong> tag.
7.Add an Order Now link using the <a> tag.
8.Create a separate CSS file and link it to the HTML using the <link> tag.
9.Style the webpage using colors, fonts, margins, padding, borders, width, text alignment, and border-radius.
10.Save the files as index.html and style.css.
